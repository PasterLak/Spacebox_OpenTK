|------------------------------------------------------------------------------------------------------------------------------
	version 0.1.5
|------------------------------------------------------------------------------------------------------------------------------

New
- a block placed in free space starts a new entity turned like the player (up, right and forward follow the view), so you choose how a new build is rotated; the preview shows it
- macOS builds (Intel and Apple Silicon) from Spacebox/Build/BuildMacOS.ps1 (not tested on a Mac yet)
- Options > Audio > Output Device: pick the sound device by its name (or follow the system default); an unplugged device falls back to the default until it is back
- hotbar size per game mode (HotbarSlots, HotbarRows up to 3): Creative has one row of 15, number keys pick the first 10, the wheel all; items in removed slots move to the inventory or drop (also on load)
- creative Fill Tool (bucket): select an area, Alt+click picks the block, Enter fills the empty cells (works in multiplayer)
- creative Copy Tool: select an area, Enter copies, LMB pastes with a box preview, R rotates (works in multiplayer)
- radar works: shows nearby ships, players and mobs as they are swept (colours per kind); round display without gray corners; energy use in the title
- commands: /hit [player] <damage>, /set <hp|power|air> <value> [player], /skin <color> [player] (synced, saved per world in skins.nbt)
- server statistics: most players today and ever, players per day, joins, different players, play time, running time; stats command and dashboard panel
- GameSet editor rebuilt on the new retained UI: every page (blocks, items, projectiles, recipes, disassembly, loot, mobs, generation with biome map, tutorials, sounds, atlases, all files) with property grid, 3D previews and summaries
- GameSet editor tutorials: outline of chapters and steps, the editor shows only the selected step or chapter, add/move/duplicate/delete steps and chapters
- Player/spawn_parameters.json: start items with their place (hand, hotbar slot, inventory, equipment), start health/power/oxygen (also on respawn), preferred spawn biome and distance from the center
- GameSet editor: Player spawn, Disassembly, Tutorials (outline, step card, problems) and Sounds (play, where used) panels, crafting category order and preview, block previews show models, atlas fits the window; Debug/Release builds also save editor changes into the source GameSet
- asteroid shapes (new worlds): 70% of asteroids roll their own form (30% stay classic): lumpy stretched blobs with lobes, double asteroids, rare donuts, Pac-Man mouths and bites, craters; no floating blocks
- generation options for new worlds: biomes, asteroid types and ore veins by distance from the world center, biome density, spacing, size and ore multipliers, worm settings per biome, hollow asteroids, round caves, veins by depth or only near caves, fallback biome; old worlds keep generating exactly as before (generator version in world.json)
- asteroids decide which mobs live in them (Mobs list: chance, max per chunk and per asteroid, layers, depth, light, biomes, distance); parasites now live in medium, heavy and icy asteroids, not in light ones
- GameSet editor biome map: distance rings and a switch for old worlds
- signs: Steel Sign (1x1), Wide Steel Sign (2x1) and Info Panel (2x1, glowing text) on any block side; wide signs are real multi-cell blocks; WYSIWYG text editor with bold, colours, alignment, text size slider, Fill (biggest text that fits) and Reset style; up to 60 characters per line on 1x1 signs and 120 on 2x1; saved and synced in multiplayer; new signs are blocks.json entries (Type sign + Sign settings)
- picture frames: iron and plastic frames in 1x1, 2x1 and 2x2 (thin plate with a raised 3D rim), right click with a picture in hand hangs or swaps it, with anything else takes it out; picture tooltips show the artwork; 30 craftable pixel-art pictures (polymer fiber + dusts) in the new Decor crafting category; each frame lists the pictures it accepts; saved and synced in multiplayer
- server keeps each player's game mode in the player's save file (GameMode, set with gm or on the dashboard, clients cannot change it) and gives it back on rejoin; dashboard shows and changes game modes of online and offline players
- dashboard Map page: rotatable 3D map of the space around the players (asteroids sized by radius, ships, players with names, claims with owner and state, untouched / saved / unsaved entities)
- world converter: 0.1.2 worlds convert to 0.1.5, older ones are refused
- world upgrade tools for NBT (rename/remove blocks and items), check for unknown ids
- dedicated server upgrades old worlds on start
- web dashboard for the dedicated server (http://server:port/dashboard): one-time setup key, admin login, server info, CPU/RAM/ticks charts, players with inventories, kick/ban/mute, bans and whitelist, live console with commands, settings, server icon, save/restart/stop
- server console command restart
- dashboard HTTPS with a certificate file (Let's Encrypt for DuckDNS), auto reload on renewal, internet HTTP redirected to HTTPS; guide Documentation/dashboard-public-access.md
- automatic HTTPS for any address: PublicAddress (DuckDNS name + token, Cloudflare domain + token, any other name or a public IP via port 80); the server gets and renews the Let's Encrypt certificate itself and keeps a DuckDNS name on the current IP
- merging item pipe (inputs bottom, left, right, output top); pipes have configurable input sides
- repair tool: shows block durability under the crosshair and repairs damaged blocks, multi-cell blocks as a whole, weakest cell first (synced in multiplayer)
- new Tools crafting category (repair tool, flashlights, radars), category rows set in crafting.json (drills in the second row), bombs in Weapons after the guns (items before blocks in every category)
- all blocks and items have short descriptions without numbers, parameters moved to tooltips
- compact equipment window: armor slots in body order, devices column, rotatable 3D player preview with skybox, armor, held item, skin colour and world lighting; drop equipment on the preview to wear it
- Spacebox Server Guide.pdf shipped with the game (server, config, port forwarding, DuckDNS, dashboard, commands, troubleshooting)
- new power blocks from Corneroids: Powerful Cobalt Power Block (1x2x1, 125 EU), Standard Nuclear Power Block (2x2x2, 180 EU); the 2x3x2 nuclear block is now Powerful Nuclear Power Block
- cobalt crystal removed (item, craft, crusher recipe); old worlds get cobalt ingots instead
- Standard Cobalt Power Block is now 1x2x1 with the Corneroids textures; tutorial text updated
- nuclear power blocks explode when shots or an explosion bring a cell to 0 durability: radius 3, low penetration (aluminium and light iron break), deadly only up close, a full titanium set survives
- loading repairs multi-cell blocks: a block that became bigger grows into free cells or is removed if it does not fit, cells without their origin are removed
- screen space ambient occlusion (SSAO) on blocks, mobs, players and the held item; Graphics options: quality Off/Low/Medium/High and strength
- Graphics options: brightness, contrast, saturation, vignette strength, film grain (animated or static), Show FPS counter, reset buttons for image and SSAO
- viewing through a ship camera block shows a security camera feed: scanlines, grain, lens distortion, REC overlay with timer (Camera Block Effect option)
- server gameplay rules: PvP (weapons, drills, ship cannons and bombs of other players), explosions on/off, explosions break blocks, explosions hurt players, explosions respect claims, friendly mobs; set in serverconfig.json "Gameplay", on the dashboard Settings page or with the gamerule command (also /gamerule in chat), applied at once and announced in chat
- keep inventory rule (on by default): with gamerule keep_inventory off (or keepinventory) survival players drop their hotbar, inventory and equipment where they die; death drops last death_drop_minutes (default 10, 1-1440), also on the dashboard and in serverconfig.json; dead players do not pick items up; drops keep their remaining time when saved
- single player and hosted worlds save their gamerules in the world folder (rules.json); clients get the server's rules
- cable blocks connect automatically: they turn along the line, the middle block of an L becomes an angle and a block with 3 or more connections a hub (only the cable block is crafted); new angle and hub textures
- Minecraft-like tp: tp <x y z> | <target> | <player> <target> | <player> <x y z>, ~ relative coordinates, @s and @a; also teleport; tphere <player> brings a player to you; same command in single player, host, dedicated server and chat
- Mods -> Ship viewer: browse the player-built ships of every saved world and look at them in a 3D preview (rotate, zoom, skybox); older worlds are converted in memory only
- DNA reconstructors work from anywhere: they are remembered while unloaded (reconstructors.json), the server loads only the reconstructor's entity by id and revives remote players too; entity saves moved from the sector folders to Entities/ with an entities.index (older worlds are converted)
- GameSets in folder format: one folder per block/item with its JSON, textures, emission maps, sounds, blueprint and recipes; old flat blocks/items/crafting/recipes.json still load and can be mixed; Default converted (content identical), converter in the editor and Tools/Spacebox.GameSetTool
- extension GameSets ("Extends", "Includes"): add or patch blocks, items, textures, sounds and recipes of a base GameSet, chosen per world in Create World and saved with it, synced and checked when joining a server; example GameSets/ExampleExtension
- texture packs: Mods -> Texture packs, several active at once in an ordered stack, override block/item/emission/UI textures of any GameSet; example TexturePacks/ExamplePack
- game folder: Mods/ holds GameSets/, Extensions/ and TexturePacks/; Multiplayer/ holds client.json, serverconfig.json, the server guide, server icons, Dashboard/, cached server worlds (Worlds/) and downloaded server content (Mods/); old folders are moved on the first start
- servers share texture packs: TexturePacks in serverconfig.json (a host shares its enabled packs), downloaded and checked with the GameSet like extensions, shown below the player's own packs
- multiplayer: the server checks every player's items (survival): pickups, chests, crafting, gifts, placing blocks, dropping and tutorial rewards are counted on the server; items a client creates by itself are removed again. No delay for the player
- server commands: whois <player> (address, ping, game mode, position, admin/muted), kickall [reason], list (players with ping), seed (also in single player)
