# Single-player bug hunt (2026-10-22)

Scope: single-player game (generation, saving, machines, inventory, player, UI). Multiplayer, server, dashboard, cannons, the DNA reconstructor, GameSet formats, the CanvasUI layout and the ship viewer were left to other work. Findings already listed in `review-2026-10-21.md` are not repeated.

Line numbers refer to the code after the fixes on branch `worktree-agent-aa76f397c948f2f9b` (based on `test-0.1.3`).
