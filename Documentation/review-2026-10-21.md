# Code review notes (2026-10-21)

Findings from the night review that are **not fixed yet**, most important first. Fixed items are in `Spacebox/DONE.txt` (0.1.5, Fixes).

## Multiplayer (design-level)

1. **The server trusts client inventories.** `ContainerServer.HandleChange`/`Merge` accept positive deltas (items the client says it put in), `DropNetwork.OnSpawnRequest` spawns up to 10000 of any item anywhere without a rate limit, and `NetworkSession.OnPlayerData` stores the inventory JSON the client sends. A modified client can create items. Long term: server-side inventories. Short term: rate-limit and range-check drop spawns, reject non-finite vectors.
2. **No reach checks** for containers (`ContainerNetwork` Open/Change), block edits/damage (`WorldEditNetwork`) and ship mounts (`ShipNetwork.OnMount`). Compare the server-side astronaut position with the target cell.
3. **No server-side game mode.** Bulk erase/fill (`WorldEditNetwork.OnBulkEdit`) is accepted from survival players. Keep the game mode per player on the server (world mode + `gm` overrides) and require creative.
4. **Item gifts can be duplicated** (`ItemGiftNetwork`, `AstronautNetwork.ReportGiftResult`): the receiver decides success and the giver refunds on timeout. The server should track pending gifts (giver, target, deadline) and only accept a result from the target.
5. **Positions and health are owner-authoritative** (no speed/teleport limit, client decides death). `tp x y z` / `tplocal` work on any server without admin rights (`ServerCommandForwarder.ShouldForwardTeleport` only forwards non-numeric arguments) — needs a server-side teleport and admin check.
6. **Login lockout and guessing:** a pending login (`ServerAuthService`, 180 s timeout) blocks the name ("Name is already taken") and failed attempts are counted per connection only. Shorter pending timeout, let a correct login replace a pending one, lock out per name and IP.
7. **Request floods from joined players:** `NetTransferService` (no limit per peer), `SectorNetwork` manifest requests, `EntitySync` requests (whole entity serialized on the main thread), `MobSpawnNetwork` (no global mob cap, no check that the spawner item is held). Unjoined peers are now blocked by the admission gate.
8. Not verified: block edits that arrive while a client is still downloading entities, `ReplicationSystem.OnVariablesMessage` returning halfway through a message, per-peer caches not cleared on disconnect (LiteNetLib reuses peer ids).

## Game / engine

1. **`MultiblockRepair` deletes the origin block (and storage contents) when completion fails** (`Spacebox/Game/Generation/Tools/MultiblockRepair.cs:57-61`) — keep it as a single cell or drop the items first.
2. **Raw `GL.BlendFunc` calls bypass `GLState`** (`FlashlightBeamRenderer`, `WorldLines`, `VisualDebug`, `ImGuiController`, `MaterialBase`), so the cached blend function can drift from the real one; route them through `GLState.BlendFunc`.
3. **Block durability is not saved** (`ChunkToTag` writes id, direction, rotation, multi-cell offset only) — damage and repairs reset on reload. Maybe intended.
4. `WorldUpgrader.Restore` deletes the world folder before moving the restored copy in; if the move fails, only the backup zip is left.
5. `Chunk.CreateLOD` passes the live `Blocks` array to a worker while the main thread may edit it.
6. `ResourceProcessingGUI.Activate` subscribes `OnCrafted` on every open (duplicate sound).
7. Translucent blocks: the new transparent pass covers models and particles; chunk meshes still draw transparent blocks as cutout. Real glass would need a separate per-chunk transparent mesh drawn through `TransparentQueue`.
8. The UI showcase uses ~130 draw calls because every item icon is its own texture; with the game's item atlas (one texture) it would be a handful.

## Environment notes from testing

- WSL on this PC fell back to "no NAT" networking, so a Windows client cannot reach a server running inside WSL. The Linux server itself works (dashboard answers inside WSL).
- Linux players need `libopenal1` for sound; without it the game now runs muted instead of crashing.
