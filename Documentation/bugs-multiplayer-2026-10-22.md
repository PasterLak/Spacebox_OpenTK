# Multiplayer bug hunt (2026-10-22)

Scope: `Engine/Networking`, `Engine/Web`, `Spacebox/Network` (host, client, dedicated server, join/auth, state sync, authority checks, admin and chat commands, dashboard, shutdown, threading, malformed packets). Findings already listed in `review-2026-10-21.md` (client-side inventories, owner-decided health, soft movement checks, unchecked mob spawner items) are not repeated. Line numbers refer to the code after the fixes. Branch: `worktree-agent-a27ce534ef9d4a7b3` (based on `test-0.1.3`).
